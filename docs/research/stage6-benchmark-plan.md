# 第六期：可复核的全流程评估与验证

方案日期：2026-10-20（Asia/Shanghai）。开发分支：`feat/stage6-benchmark-evaluation`。

## 目标和范围

把“输入任务 → 发现数据 → 受控工具执行 → 结果与证据 → 逐题评分 → 分层统计 → 回归门禁”
做成可运行、可复核的链路。公开开发集用于定位能力，既有 Stage 1–5 回归用于检查产品功能和治理。
两类证据分别报告。任何外部基准成绩都不能自动关闭既有生产验收门禁。

本轮实现的是复用现有 `SqlGuard`、`SQLiteReadOnlyExecutor`、CC Switch 模型加载器的
**受限 SQL 分析基线**。它有真实模型调用、数据库执行与工具轨迹，但不是现有生产 Supervisor
在这些新数据源上的资格认证，也不具备任意 Python、机器学习训练、多模态或浏览器能力。
遇到超出当前工具能力的题目保留在分母中，不能挑掉难题后声称完整 Data Science Agent 成绩。

## 全流程协议

1. **来源与环境资格**：逐文件校验哈希；下载和执行分开；BIRD 先跑官方参考 SQL，识别
   数据版本、执行超时和结果规模约束。环境问题不能归类成模型逻辑错误。
2. **选择队列**：种子 `20261020`，按难度×数据库/文件分桶，桶内固定洗牌、轮转。
   抽样函数从不读取答案。保存明确的 case ID 与队列哈希；DABstep dev 全量。
3. **答案隔离**：模型只收到 Task、允许的 schema/1 行样例（长文本标记截断）和必要业务文档；没有 golden
   label、gold SQL、评分器或其它样本文件工具。每个进程只接受本题 DTO，不传 Case。
   这是工具与输入层隔离，不宣称本地进程具备生产沙箱的文件系统安全边界。
4. **执行预算**：最多 6 轮动作、24,000 已上报 token、每请求 30 秒接口超时、整题
   125 秒进程强制截止。SQL 查询超时 5 秒、结果 200 行、只读固定数据库、schema 范围检查。
   无接口自动重试、任意代码、shell、数据库写入或其它数据源扩权。
5. **评分与证据**：InfiAgent 字符串精确相等或有限数绝对误差 `<1e-6`（核对上游评分源码）；
   DABstep 使用披露的本地数值/字符串/列表规则；BIRD 比较真实执行的结果，保留重复行、NULL、
   列顺序及数值容差，行顺序在本地协议中忽略。没有调用上游官方评分器，因此不报官方 EX/VES。
   非 SQL 最终答案必须引用成功工具步骤；步骤引用有效性不等于完整语义蕴含验证。
6. **可观测性**：保存 SQL、结果摘要哈希、行数、耗时、错误类别、最终输出、数据库哈希、
   模型/提示/代码/运行协议指纹和 token。耗时包含子进程启动。缺失 token 为未知/部分数据，
   超时进程的零已观测 token 不能解释成零消耗；成本未取得可信报价时为 null。
7. **统计**：任务 pass@1、子答案准确率、难度切片、失败类型、P50/P95、Wilson 95% 区间。
   固定分层开发样本的区间只描述本轮任务，不声称随机总体推断、污染消除或隐测成绩。
8. **门禁与回归**：校验逐题证据并重算摘要；拒绝缺失/重复样本、不可比协议、伪造摘要和
   非有限遥测。配对成功→失败单独阻断，严重事件不能由正确率抵消。缺成本、重复稳定性、
   独立人工复核、生产 Supervisor、影子/灰度证据均保留未完成。

初始内部诊断阈值：各轨道 60/60/10 题，任务成功率至少 80%、P95 不超过 120 秒、模型服务
失败率不超过 5%、严重事件为零。这些是本项目拟定的可调目标，不是基准作者标准，也不是
凭单轮试验就能满足的上线承诺。不同轨道分别判定，不加权成一个万能分数。

## 实施与验收顺序

| 工作包 | 可复核产物 | 验收方式 |
|---|---|---|
| 6A 来源与计划 | 本文件、冻结下载器、来源与数据库 manifest | 官方链接、版本、文件哈希；无原始数据入库 |
| 6B 适配与评分 | 三类 Case/Task 适配、数值与表结果评分 | 错误数值、重复行、NULL、遗漏子答案和串通答案测试 |
| 6C 受控真实运行 | 独立进程 SQL Agent、逐题报告 | 活模型、真实库、预算、引用步骤、前后数据库哈希 |
| 6D 全项目回归 | Stage 1–5 报告、完整测试与覆盖率 | 既有产品行为和治理门禁保持可运行 |
| 6E 发布诊断 | 非补偿门禁、配对比较、退出码和阻断清单 | 证据缺失、协议不一致、严重事件必须阻断 |
| 6F 外部资格 | Python/OCI、Spider 云环境、人工复核、重复/新鲜集、影子与灰度 | 后续明确环境与复核主体；无证据维持未验收 |

第六期本轮交付 6A–6E 的代码、真实运行和结果分析，6F 是明确的后续资格工作。不得把本轮
受限基线解释为全部产品能力、完整学术基准复现或生产发布验收。
