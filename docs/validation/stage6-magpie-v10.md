| InfiAgent-DABench | 32/60 | 53.3% | 62.99 | 325,076 | 0 |

所有正式样本均保留在分母，未把失败任务剔除或拼接成功案例。三份正式报告的 130/130 条评分判定均经无模型回放一致；这是判分重现，不是 130 题全部正确。来源清单、数据库哈希、评分器/运行器/工具摘要和逐题轨迹均已核对。

六题校准分别为 BIRD 4/6、InfiAgent 4/6、DABstep 1/6，均有完整遥测、无服务错误，服务预检通过后才启动对应正式批次。校准成绩单独记录，不与正式成绩相加；服务可用性不等于答案正确率。

不同型号、工具策略和协议的历史分数不能作为严格算法配对。这里验证的是 Magpie 路径的真实运行结果，不作官方榜单、总体泛化或模型权重版本保证。三个轨道曾并行运行，另有少量限时接口探测和 Supervisor 请求重叠，延迟不是独立性能基准。费用未独立取得，保持 null；token 为 SDK 遥测，输出上限是请求参数，不是完整账单保证。

## 实际 Agent 流程与接口边界

三个 TLC 认证指标实际 Supervisor 全部完成（3/3），每题只执行一次认证指标查询；请求绑定一致、数值与确定性路径匹配、发现/分析/Verifier/Reporter 四角色齐全，证据哈希验证通过，数据库保持不变。三个完成时间分别约 39.61、28.95、34.30 秒。这个结果用于产品编排和证据链验证，不是三个公开数据集的替代成绩，也不是独立第三方数值引擎验收。

普通 Chat 和 Responses 接口均完成实际调用；早期 Chat 小探测曾返回非法 JSON，原生 Responses JSON schema 叙述也曾返回普通文本而被严格拒绝，负面证据均保留。标准函数调用结构化结果通过同一 Narrative 校验，修复后的原叙述入口约 2.14 秒完成。模型在工具参数中自报的型号不可信，叙述元数据继续由已选择路由覆盖；没有放宽 schema 或自动切换型号掩盖失败。
