新增反例覆盖拼写碰撞、截断域拒绝、授权表范围、字节不变和可选探测超时降级。这些后续增量仍与冻结全量模型评估分开记录。

## 防止常量 SQL 冒充数据证据

后续研究配置的答案绑定检查 SQL 输出依赖：纯常量、CTE 中包装的常量、无数据来源的硬编码统计值不能因 SELECT 成功而成为答案证据；完整集合与交叉检查路径也执行同一边界。均值、物理字段、基于数据行的 COUNT(*) 和条件分类有反例验证。未支持的谱系形式保守不认证，最终证据需显式投影；固定分析工具继续使用其完整数据产物。
