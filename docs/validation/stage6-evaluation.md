1. 早期 BIRD 任务输入仅笼统写“SQL tasks”，模型返回文字答案。修复为显式 `required_output`
   并加入格式纠正和回归测试。中断的旧轮只有 partial，未纳入完整成绩。
2. 模型 SDK 的接口超时不能保证整题截止。引入独立进程，超时由父进程终止并标记未知消耗。
3. 上游 InfiAgent 评分源码采用精确字符串/绝对误差 `<1e-6`，初始设计中的相对容差已在正式
   运行前收紧，测试覆盖不能把近似或子串误计正确。
4. 任务错误、模型错误与参考 SQL 环境错误分别保留；不靠剔除失败抬分。
5. 发布诊断重算摘要、拒绝坏遥测/重复轨道/不可比数据快照，并保留成本和外部验收缺口。

另保留当前 GLM 路由的早期完整诊断：InfiAgent 2/60，DABstep 0/10，主要为限流和超时。
